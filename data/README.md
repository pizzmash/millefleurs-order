# カクテルマスター

`raw/`には `/home/daxubar/python/cocktaillog_crawler/data` の6つのCSVをコピーして保存しています。アプリはこのプロジェクト内のコピーを取り込み元として使い、元ディレクトリに実行時依存しません。

`source-manifest.json`はコピー時の件数とSHA-256です。CSVとこの記録はGit管理します。

## 正規化方針

取り込み処理で空欄kind_idをnullにし、検索用文字列をNFKC正規化、度数を数値と原表記に分けます。IDと外部キーの対応、表示名、分量の原表記は保持します。kind_idによる代用グループは勝手に変更しません。

今回コピーしたCSVは原本と同一で、データ変換はまだ行っていません。正規化処理はアプリ実装時に再現可能なコードとして追加します。生成DBや注文・在庫などの運用データはGit管理しません。
