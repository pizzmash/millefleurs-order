## ADDED Requirements

### Requirement: 在庫一覧の表示
システムは在庫登録画面で常備材料を除外し、種類ID昇順、同種内は日本語の材料名順、同名は材料ID昇順で表示すること（SHALL）。未分類は末尾とし、画面内に「水・氷は常備」や同趣旨の説明を表示しないこと（SHALL）。

#### Scenario: 一覧を開く
- **WHEN** 家主が在庫登録画面を開く
- **THEN** 同じ種類が連続し、未分類が末尾に並び、常備材料と常備品説明は表示されない。

#### Scenario: 検索と絞り込み
- **WHEN** 家主が検索または「すべて」「お酒」「割り材・その他」「あるもの」で絞り込む
- **THEN** 常備材料は表示されず、結果は同じ表示順を維持する。

#### Scenario: 在庫更新
- **WHEN** 家主が材料の在庫を切り替える、または在庫を更新する
- **THEN** 同じ表示順を維持し、水・氷は引き続き登録なしで作成可否の判定に使用される。
