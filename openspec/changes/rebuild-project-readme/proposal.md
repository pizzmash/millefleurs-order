## Why

READMEが短い開発メモに留まり、初めて訪れた人が用途、起動条件、開発への参加方法を判断しにくい。OSS公開を見据え、実装に裏付けられたプロジェクトの入口へ整備する。

## What Changes

- READMEを概要・機能・利用フロー・構成・セットアップ・開発・運用・データ・参加方法・ライセンスの順に再構成する。
- `.env`と`.dev.vars`を含め、初回起動に必要な設定と確認方法を記載する。
- 現行クラウド版と旧LAN版の資料を区別し、詳細手順への導線を設ける。
- 未設定のライセンスと第三者データの確認事項を正確に示す。

## Capabilities

### New Capabilities

なし。文書のみの変更として`.openspec.yaml`に`skip_specs: true`を設定する。

### Modified Capabilities

なし。アプリケーションの振る舞いは変更しない。

## Impact

README.mdと本changeの文書。実行コード、依存関係、デプロイ設定、既存specに変更はない。
